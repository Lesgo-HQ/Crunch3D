# Getting help

Start with the [setup instructions](README.md#getting-started), [limitations](README.md#limitations), and local API documentation at `http://localhost:8000/docs` while the backend is running.

Search [existing issues](https://github.com/Lesgo-HQ/Crunch3D/issues) before opening a new one. For setup questions, include your operating system, Python and Node versions, the command you ran, and the relevant error. For mesh problems, include settings and a small reproduction you are allowed to share. Remove credentials and private information.

Use the issue templates for reproducible bugs and feature requests. Use a blank issue for a setup question. Security reports follow [SECURITY.md](SECURITY.md); conduct reports follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is provided by contributors as time allows. There is no guaranteed response time.
